Instalar Media Forge Lab

Use o menu de três pontos do navegador, junto à barra de endereço.

Chrome no Windows
  1. Abra ⋮ no canto superior direito.
  2. Escolha Transmitir, guardar e partilhar (ou «Transmitir, salvar e compartilhar»).
  3. Escolha Instalar página como aplicação… e confirme.

Ajuda oficial do Chrome ↗

Edge no Windows
  1. Abra … no canto superior direito.
  2. Escolha Mais ferramentas → Aplicações. Em algumas versões, «Aplicações» aparece diretamente no menu.
  3. Escolha Instalar este site como uma aplicação e confirme.

Ajuda oficial do Edge ↗

Chrome no Android
  1. Abra este endereço no Chrome.
  2. Toque em ⋮ → Instalar e criar atalho → Instalar.
  3. Noutras versões, procure Adicionar ao ecrã principal → Instalar.

Ajuda oficial do Chrome Android ↗

Se a opção não existir, verifique se Media Forge Lab já está nas aplicações do dispositivo. Se estiver num navegador integrado noutra aplicação, abra o endereço diretamente no Chrome ou Edge.

No Windows deste computador, use o endereço local instalável. No Android, use o endereço HTTPS da rede de casa, com o certificado local configurado.

A aplicação continua a precisar do computador ligado. Os vídeos não são guardados para utilização offline.

Definições

Instalar no Android

Na sua rede de casa, instale o certificado local e abra o endereço HTTPS indicado no guia. Depois escolha «Adicionar ao ecrã principal» → «Instalar» no Chrome.

Descarregar certificado público local

O certificado é apenas para o Media Forge Lab desta casa. Não contém a chave privada nem dados do fornecedor. Os vídeos nunca são guardados para reprodução offline.
